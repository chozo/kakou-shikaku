# 囲う□（かこうしかく）

3×3の盤面でコンピューターと線を置き合う、時間制限なしのミニWebゲーム。
企画「一手で四角、タイルの陣取り」がもとです。原案の90秒制限は採用せず、全9マスを取るまで遊べます。

## 起動

```sh
npm install
npm run dev
```

http://127.0.0.1:5173 を開きます。ランタイムの外部依存・サーバー保存はありません。公開時は必要な9ファイルをビルドで取り出します。静的HTTPサーバーから配信できます。

## 操作・ルール

- 「1手戻る」で直前の自分の1本と、その後のCPUの応手（連続獲得を含む）を取り消し、自分の手番に戻せます。連続獲得中は最後の1本だけ戻します。どちらかが5マスを獲得して勝敗が確定した時点で無効になり、結果画面からも戻せません。線・獲得マス・点数・最後の線の表示を復元します。CPU先手の初動は取り消せません。再戦・タイトル復帰では履歴をリセットします。
- 空いた辺をタップ／クリックして1本置く。キーボードはTabで辺を選びEnter／Space。
- 四辺を完成させた側がマスを獲得し、続けて打つ。1本で2マス完成した場合は両方を獲得。
- 取れなければ交代。全9マスの獲得後、5マス以上取った側が勝利。1マス100点。
- 開始画面でCPUの強さ「はじめて・ふつう・げきつよ」と、自分の「先手・後手」を選択。初期値は「はじめて・先手」。選択はブラウザ内に保存し、再戦にも引き継ぎます。結果画面の「メニューに戻る」で変更できます。
- グレーの初期辺は中立。難易度別に4種の配置を使います。「はじめて・先手」だけは初手で1マス取れます。それ以外の全配置では、誰がどの辺を置いても初手に四角は囲めません。
- トップに基本ルールを表示し、「メニューへ」で対戦設定へ進みます。終了画面は「トップに戻る」（ルール画面）と「メニューに戻る」（対戦設定）の2択。戻ると対戦履歴・音をリセットし、難易度・手番の選択を保持します。メニューからの再戦は同じ初期配置です。
- 音は初期ON。「はじめる」を押すとBGMが流れます。右上の音ボタンでBGM・効果音をまとめてON／OFF。音が使えない環境でもプレイ可能。
- 遊び方・やり直しの確認中、およびタブが非表示の間はAIの着手を待機。

## 設計

- `src/game.js`: 24辺・9マスの状態、獲得判定、手番、AI。旧軽量AIは比較テスト用に残しています。実際のCPUは `src/ai.js` を使用し、「はじめて」の25%の着手と「ふつう」の同評価手の選択でこの軽量AIを使います。
- `src/main.js`: SVG描画、Pointer相当のclick操作、UI状態、音の再生タイミング。AI待ち450ms、結果表示待ち850ms。
- `src/ai.js` / `src/ai-worker.js`: 「はじめて」は75%の着手をランダム、25%を獲得・安全重視の軽量評価で選択。「ふつう」は3手先を探索（残り6辺以下は完全探索）。「げきつよ」は最初から終局まで完全探索し、同評価の最善手だけランダムに選択。Web Workerで先読みし、再戦・ヘルプ・タブ非表示時には古い計算を中止。Workerが利用できない場合は同じ探索をメインスレッドで実行。
- `src/game.js` の `OPENINGS`: 「はじめて・後手」「ふつう」「げきつよ」でそれぞれ別の初期配置を使います。ふつうは辺の少ないマスが多い配置、げきつよは2辺が置かれたマスが多い配置。全配置で初期辺は5本。ふつう・げきつよの8配置は最善手同士で先手5対後手4となることを検算済み。旧設定の `strong` は `normal` に読み替えます。
- `src/audio.js`: Web Audioで合成するオリジナルの8小節ループBGM（92 BPM）と、開始・着手・獲得・2マス同時獲得・勝利・敗北の効果音。BGMは対戦中のみ。結果・タイトルでは停止し、タブ非表示時は効果音も止めます。音量はマスター0.55、BGMの旋律0.065、着手音0.1、獲得音0.14。外部音源の取得は不要。
- `src/style.css`: 縦画面中心のレスポンシブ表示。色と○／×の両方で所有者を表示。
- 画像はSVGとCSSで描画。外部画像・フォント・音素材は使用していません。
- `window.__game`: 状態取得、開始、着手、AIの一手、結果表示、タイトル復帰のブラウザ確認用入口。

npm run check

### プロモーション動画

- `promo-video` スキルの撮影ツールを `tools/promo/` に配置。縦型1080×1920、30fps、30秒。
- 実際のゲーム操作を再生し、2マス同時獲得 → タイトル → 操作・連続獲得 → 勝利 → 難易度メニュー → 公開URLの順に構成。
- `?promo=1` の撮影時のみ `__game.manual/step/state/drainEvents` と効果音のオフライン出力を使用。盤面・得点は通常のルール処理で更新。通常プレイのタイマーは維持。
- 音源はゲーム内のオリジナル合成効果音と、撮影ツールのWeb Audio合成リズム。外部音源なし。
- `npm run promo`: 本編MP4・表紙・確認用一覧を隣接フォルダ `../video/` に出力。
- `PROMO_EVERY=15 npm run promo`: 15コマおきの構成確認。`PROMO_ENCODE_ONLY=1 npm run promo`: 保存済みコマから再エンコード。
- 動画と中間ファイル `../video/work/` はアプリの公開ビルドに含めません。
- 完成品の確認（2026-10-11）: 30.00秒、1080×1920、30fps、H.264 High / AAC 192kbps・44.1kHz。効果音22回。最終音量 -13.9 LUFS、真のピーク -1.9 dBTP、音割れなし。
- 共通撮影ツールはそのまま使用し、`finalize-audio.mjs` で今回の音源に0.3dBの最終調整を適用。`npm run promo` で続けて実行します。
